# Agent Office 3D Asset Pipeline

## Purpose

This contract keeps Office assets visually consistent, licenseable, performant, and replaceable without moving workflow truth into the renderer.

## Production asset tiers

1. **Tier A — authored Office pack**
   - authored or intentionally modified in Blender;
   - exported as GLB/glTF 2.0;
   - source `.blend` retained outside the runtime bundle or in the approved design-source location;
   - explicit license/provenance record;
   - normalized origin, scale, materials, bounds, and naming.
2. **Tier B — curated external kit**
   - current Kenney furniture kit;
   - permitted as production fallback and as a visual baseline;
   - restyled by Agent Office material policy before mounting.
3. **Tier C — procedural primitive fallback**
   - generated by `environment.ts`;
   - always safe as a load-failure fallback;
   - never presented as a Blender-authored asset.

## Blender authoring contract

Use Blender with metric units and apply transforms before export.

```text
Units: Metric / meters
Forward: -Z
Up: Y
Origin: meaningful floor-contact or pivot point
Transforms: applied
Mesh names: ao_<room>_<asset>_<variant>
Materials: ao_<surface>_<variant>
Textures: embedded in GLB when used
Animation: only when the asset itself needs it
```

Target budgets for ordinary room props:

```text
Static prop: <= 20k triangles preferred
Hero prop: <= 60k triangles with justification
Materials per prop: <= 4 preferred
Textures: 2k max preferred, 1k for ordinary props
Runtime lights inside GLB: prohibited
Scripts/drivers: prohibited
```

## Required provenance metadata

Every authored or third-party pack must record:

- asset name and semantic purpose;
- source/author;
- license;
- source URL or internal source reference;
- authoring tool and version;
- export date;
- approximate triangle/material/texture budget;
- expected room/floor;
- replacement/fallback asset.

## Runtime rules

- Asset loading may change presentation only.
- Asset failure must not block Task, Run, AgentRun, Event, Evidence, or Finding workflows.
- A GLB may not encode or fabricate workflow status.
- Production mounts must retain deterministic bounds checks.
- Repeated furniture should use instancing where practical.
- `MeshStandardMaterial` is the default material family so time-of-day lighting remains coherent.
- Emissive surfaces must stay restrained; screens may glow, desks may not become light sources.

## Current Phase 14 state

The Build floor uses the curated Kenney GLB kit as Tier B production furniture with a refined Agent Office material policy. Procedural geometry remains Tier C fallback. Phase 14 also establishes this Blender-ready Tier A contract, but it does **not** mislabel the existing Kenney binaries as Blender-authored Agent Office props.

A future custom pack can replace Tier B asset-by-asset without changing the Office truth model or renderer API.
