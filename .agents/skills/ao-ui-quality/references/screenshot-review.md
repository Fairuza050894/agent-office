# Screenshot Review

Screenshot review is required for meaningful visual changes.

Inspect at minimum desktop around 1440px, compact desktop/tablet around 1024px, and mobile around 390–430px when the changed surface is user-facing.

Review in this order:

1. hierarchy
2. density
3. scanability
4. truthfulness
5. empty-state usefulness
6. typography and technical data treatment
7. repeated cards, pills, uppercase labels, and borders
8. responsive behavior
9. accessibility
10. stale copy such as phase names and runtime claims

Automated tests prove functional behavior, not visual quality. Do not report visual hardening complete until a human or visual-capable reviewer has inspected the rendered result.
